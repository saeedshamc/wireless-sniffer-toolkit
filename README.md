# Wi-Fi Monitor Suite v2

نرم‌افزار گرافیکی (PySide6) برای مانیتورینگ خودکار وای‌فای: مانیتور مود،
channel hopping خودکار، کپچر با tshark، و نمایش زنده‌ی بسته‌ها/SSIDها روی
یک داشبورد با تم تیره. الان روی هر سه پلتفرم (لینوکس/ویندوز/مک) اجرا
می‌شه، با این تفاوت که سطح واقعیِ پشتیبانی هرکدوم متفاوته (زیر توضیح داده شده).

## ساختار پروژه

```
wifi_monitor_suite_v2/
├── main_gui.py              # رابط گرافیکی (PySide6)
├── requirements.txt
├── README.md
└── core/
    ├── base_engine.py       # قرارداد مشترک موتورها + ثابت‌های کانال
    ├── platform_utils.py    # تشخیص OS و پیدا کردن مسیر ابزارها
    ├── capture_display.py   # پارس زنده خروجی tshark برای جدول SSID/شمارش بسته
    ├── engine_linux.py      # موتور لینوکس (پشتیبانی: کامل)
    ├── engine_windows.py    # موتور ویندوز (پشتیبانی: جزئی/best-effort)
    ├── engine_macos.py      # موتور مک (پشتیبانی: تجربی)
    └── engine_factory.py    # انتخاب خودکار موتور بر اساس OS
```

## نصب

```bash
pip install -r requirements.txt
```

به‌علاوه‌ی ابزارهای سیستمی:

**لینوکس** (پشتیبانی کامل):
```bash
sudo apt install aircrack-ng tshark wireless-tools iw
```

**ویندوز** (پشتیبانی جزئی):
- Wireshark (شامل tshark) نصب باشه
- Npcap با گزینه‌ی **"Support raw 802.11 traffic (and monitor mode) for wireless adapters"**
  فعال نصب بشه — این گزینه `WlanHelper.exe` رو نصب می‌کنه که این برنامه ازش استفاده می‌کنه.
- برنامه رو با **Run as Administrator** اجرا کنید.
- ⚠️ اکثر کارت‌های وای‌فای امروزی روی ویندوز اصلاً OID مربوط به مانیتور مود رو
  پشتیبانی نمی‌کنن. اگه WlanHelper خطا بده، یعنی کارت شما پشتیبانی نمی‌کنه —
  این محدودیت درایور/سخت‌افزاره، نه محدودیت این برنامه.

**مک** (تجربی):
- ابزار `airport` فقط روی مک‌های قدیمی‌تر (پیش از Apple Silicon) موجوده.
- روی مک‌های M1/M2/M3 و بالاتر و نسخه‌های جدید macOS این باینری معمولاً
  حذف شده و این بخش کار نخواهد کرد.
- در این حالت، یا از یک آداپتور USB وای‌فای خارجی سازگار با مانیتور مود
  (مثل بعضی چیپ‌ست‌های Atheros/Ralink) استفاده کنید، یا از Wireshark به‌همراه
  ابزار مخصوص اون آداپتور.

## اجرا

```bash
# لینوکس/مک
sudo python3 main_gui.py

# ویندوز (در یک PowerShell/CMD با دسترسی Administrator)
python main_gui.py
```

## قابلیت‌های نسخه ۲ (نسبت به نسخه اول)

- **رابط کاملاً بازطراحی‌شده** با PySide6 و تم تیره حرفه‌ای
- **جدول زنده‌ی شبکه‌ها**: هر SSID/BSSID دیده‌شده به همراه آخرین قدرت
  سیگنال (dBm) و تعداد بسته‌های دریافتی از اون شبکه، به‌صورت زنده آپدیت می‌شه
- **شمارنده‌های زنده**: تعداد کل بسته‌ها، تعداد شبکه‌های یافت‌شده، کانال فعلی
- **پشتیبانی چندپلتفرمی واقعی** به‌جای صرفاً لینوکس:
  - لینوکس: `iw`/`airmon-ng` (کامل)
  - ویندوز: `WlanHelper.exe` از Npcap (جزئی، وابسته به درایور)
  - مک: `airport` + شبیه‌سازی hopping با کپچرهای متوالی + `mergecap` (تجربی)
- **نمایش صادقانه‌ی سطح پشتیبانی و محدودیت‌های هر پلتفرم** مستقیماً در پایین
  پنجره برنامه، تا کاربر گول قابلیت‌های غیرواقعی رو نخوره
- معماری ماژولار (`BaseEngine` + زیرکلاس هر پلتفرم) که افزودن پلتفرم یا
  قابلیت جدید رو ساده می‌کنه

## محدودیت‌های واقعی که همچنان پابرجاست

مانیتور مود یک قابلیت سطح درایور/فریم‌ور کارت شبکه‌ست، نه چیزی که با نرم‌افزار
به‌تنهایی بشه دور زد:
- **لینوکس**: فقط کارت‌هایی که chipsetشون مانیتور مود رو ساپورت کنه (اکثر
  Intel ساپورت نمی‌کنن).
- **ویندوز**: فقط با Npcap+WlanHelper و فقط روی درایورهای خاص.
- **مک**: عملاً فقط مک‌های قدیمی؛ مک‌های جدید نیاز به آداپتور خارجی دارن.

با `iw list` (لینوکس) می‌تونید مطمئن بشید کارتتون ساپورت می‌کنه یا نه.

## نکته حقوقی/اخلاقی

این ابزار مثل Wireshark و Kismet یک ابزار استاندارد تحلیل شبکه‌ست. فقط روی
شبکه‌ی خودتون، شبکه‌ی سازمانتون (با مجوز)، یا در چارچوب پن‌تست مجاز و
مستندشده استفاده کنید. کپچر ترافیک شبکه‌ای که مالک/مدیرش نیستید و اجازه
ندارید، در بسیاری از کشورها جرمه.
