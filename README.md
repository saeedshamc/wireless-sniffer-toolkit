# Wi-Fi Monitor Suite v2

نرم‌افزار گرافیکی (PySide6) برای مانیتورینگ خودکار وای‌فای: مانیتور مود،
channel hopping، کپچر با tshark، و نمایش زنده‌ی بسته‌ها/SSIDها روی
یک داشبورد با تم تیره. روی هر سه پلتفرم (لینوکس/ویندوز/مک) اجرا می‌شود؛
سطح واقعی پشتیبانی هر کدام متفاوت است (در خود برنامه و پایین همین صفحه آمده).

## ساختار پروژه

```
wireless-sniffer-toolkit/
├── main_gui.py              # رابط گرافیکی (PySide6)
├── requirements.txt
├── README.md
├── LICENSE
└── core/
    ├── __init__.py
    ├── base_engine.py       # قرارداد مشترک موتورها + ثابت‌های کانال
    ├── platform_utils.py    # تشخیص OS و پیدا کردن مسیر ابزارها
    ├── capture_display.py   # پارس زنده خروجی tshark برای جدول SSID
    ├── engine_linux.py      # موتور لینوکس (پشتیبانی: کامل)
    ├── engine_windows.py    # موتور ویندوز (پشتیبانی: جزئی/best-effort)
    ├── engine_macos.py      # موتور مک (پشتیبانی: تجربی)
    └── engine_factory.py    # انتخاب خودکار موتور بر اساس OS
```

## نصب

```bash
pip install -r requirements.txt
```

به‌علاوه‌ی ابزارهای سیستمی:

**لینوکس** (پشتیبانی کامل):
```bash
sudo apt install aircrack-ng tshark wireless-tools iw
```

**ویندوز** (پشتیبانی جزئی):
- Wireshark (شامل tshark) نصب باشد
- Npcap با گزینه‌ی **"Support raw 802.11 traffic (and monitor mode) for wireless adapters"**
  فعال نصب شود — این گزینه `WlanHelper.exe` را نصب می‌کند
- برنامه را با **Run as Administrator** اجرا کنید
- ⚠️ اکثر کارت‌های وای‌فای امروزی روی ویندوز OID مانیتور مود را
  پشتیبانی نمی‌کنند. اگر WlanHelper خطا بدهد، محدودیت درایور/سخت‌افزار است،
  نه محدودیت این برنامه

**مک** (تجربی):
- ابزار `airport` فقط روی مک‌های قدیمی‌تر (پیش از Apple Silicon) موجود است
- روی مک‌های Apple Silicon و نسخه‌های جدید macOS این باینری معمولاً حذف شده
- در این حالت از آداپتور USB وای‌فای سازگار با مانیتور مود استفاده کنید
- برای ترکیب کپچر کانال‌ها به `mergecap` (همراه Wireshark) نیاز است

## اجرا

```bash
# لینوکس/مک
sudo python3 main_gui.py

# ویندوز (PowerShell/CMD با دسترسی Administrator)
python main_gui.py
```

برنامه در استارت‌آپ، پیش‌نیازها (`check_ready`) و سطح پشتیبانی پلتفرم را
نشان می‌دهد. اگر چیزی کم باشد، قبل از شروع مانیتورینگ در نوار وضعیت قرمز می‌بینید.

## قابلیت‌ها

- رابط PySide6 با تم تیره و چیدمان RTL
- جدول زنده‌ی شبکه‌ها: SSID / BSSID / کانال / سیگنال (dBm) / تعداد بسته
- شمارنده‌های زنده: کل بسته‌ها، شبکه‌های یافت‌شده، کانال فعلی
- به‌روزرسانی جدول فقط هنگام تغییر داده (کمتر flicker)
- thread-safe: عملیات start/stop در پس‌زمینه، آپدیت UI فقط از thread اصلی Qt
- پشتیبانی چندپلتفرمی:
  - لینوکس: `iw` / `airmon-ng` (کامل) — NetworkManager موقتاً stop/start می‌شود
  - ویندوز: `WlanHelper.exe` + لیست اینترفیس از `tshark -D` (جزئی)
  - مک: `airport` + hopping شبیه‌سازی‌شده + `mergecap` (تجربی)
- نمایش صادقانه‌ی محدودیت‌های هر پلتفرم در پایین پنجره

## محدودیت‌های واقعی

مانیتور مود قابلیت سطح درایور/فریم‌ور کارت است، نه چیزی که فقط با نرم‌افزار
دور زده شود:
- **لینوکس**: فقط کارت‌هایی که chipsetشان مانیتور مود را ساپورت کند
- **ویندوز**: فقط با Npcap+WlanHelper و فقط روی درایورهای خاص
- **مک**: عملاً مک‌های قدیمی؛ مک‌های جدید نیاز به آداپتور خارجی دارند

با `iw list` (لینوکس) می‌توانید مطمئن شوید کارتتان پشتیبانی می‌کند یا نه.

## نکته حقوقی/اخلاقی

این ابزار مثل Wireshark و Kismet یک ابزار استاندارد تحلیل شبکه است. فقط روی
شبکه‌ی خودتان، شبکه‌ی سازمانتان (با مجوز)، یا در چارچوب پن‌تست مجاز و
مستندشده استفاده کنید. کپچر ترافیک شبکه‌ای که مالک/مدیرش نیستید و اجازه
ندارید، در بسیاری از کشورها جرم است.
